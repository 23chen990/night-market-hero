## 一、要解决的问题

1. **接缝硬切线**：无限横向地图由若干 `1672×941` 不透明全景图首尾相接构成，块宽 `1600`。相邻块有轻微重叠，但因为是两张不同全景硬拼，中间露出可识别的竖直切线。
2. **结构悬空**：现有前景层 `foreground-eaves-v1.png` 的飞檐只有檐角探进画面、没有可见支撑，视觉上悬空。
3. **规范不统一**：素材在色彩、尺寸、命名、目录、透明度上各资产存在漂移。

**核心原则**：不要用雾 / 半透明遮罩去「糊」接缝；而是用一段**完整、能站得住的建筑过渡**去「造桥」，同时让所有素材遵守同一套客观规范。

## 二、连接族清单（桥接图共 6 类 × 2 变体 = 12 张）

桥接图是盖在接缝上的一段**独立栅格场景**，让地平线、屋檐线、灯笼光向、水面倒影连续穿过接缝。

| 族 id | 方向 | 视觉过渡要点（含承重要求） |
|---|---|---|
| market-internal | 闹市 → 闹市 | 摊棚连廊（**立柱落地**）+ 灯笼串连续延伸，中间是更热闹的摊位巷 |
| rooftops-internal | 屋脊 → 屋脊 | 一条屋脊线交接给更高的瓦顶桥（**有桥墩/承重墙**），远处雾中楼阁 |
| waterfront-internal | 水市 → 水市 | 码头（**桩柱入水**）、船桅、水面倒影线转入下一片水巷 |
| market-rooftops | 闹市 ↔ 屋脊 | 棚廊小巷（**柱落地面**）经台阶/引桥上坡，汇入瓦顶桥 |
| rooftops-waterfront | 屋脊 ↔ 水市 | 石阶桥（**墩柱入水**）下坡到码头，倒影灯笼 |
| waterfront-market | 水市 ↔ 闹市 | 水上摊棚埠头（**桩柱撑起棚架**）转入灯笼市集边缘 |

**尺寸**：最终 `560 × 941`（宽度 `420–640` 可接受，高度固定 `941`，与全景图同高）。

## 三、建筑构图规范（8 条，桥接图核心，按此出图）

桥接图不是「贴片」，而是一段**完整、能站得住的建筑场景**，左右两端直接与相邻全景图的结构咬合。**不需要任何透明渐变 / 羽化**。

1. **承重规则（最重要）**
   - 任何屋檐/屋顶必须能看到支撑：檐柱、墙体、或明确搭接在另一栋更高建筑的檐口上。禁止悬空屋檐。
   - 棚架/雨棚：立柱 + 横梁 + 斜撑，柱子必须落地（接到地面 / 平台 / 船面）。
   - 桥：桥墩或桥拱立于水中或岸上，桥面有栏杆，两端有引桥/台阶接到两岸。
   - 牌坊：立柱 + 夹杆石（抱鼓石），横枋上以斗拱托举屋顶。
   - 灯笼：只能挂在有锚点的结构上（挑檐末端、立柱横杆、两岸间缆绳的两端锚点）。
2. **统一基准线**：全画面共用一条地平线/河岸线，高度与相邻全景图一致；所有建筑从这条线「生长」出来；水面线一致，倒影从水面线开始。
3. **统一透视**：与相邻全景图同一视平线；柱子垂直、消失点一致；近大远小比例与两侧衔接。
4. **承接关系**：左侧图 A 的最后一个结构（屋檐/码头/棚架）延伸进入桥接图，被桥接图中更近或更高的结构合理承接或遮挡；右侧同理向图 B 交棒。过渡结构的屋顶要压住两侧屋檐线的交接处。
5. **光源统一**：灯笼的高度节奏、光向、水面倒影与两侧一致；暖灯少而克制（冷蓝雾夜 + 少量暖灯的既定风格）。
6. **遮挡与纵深**：前景柱/檐遮挡中景，中景遮挡远景；被遮挡处的结构仍要合理。
7. **边缘咬合（替代羽化）**：左右边缘不做透明渐变；左缘场景与图 A 右缘的屋檐线高度、柱距节奏、地平线直接连续，右缘同理对接图 B 左缘。结构线（檐口线、栏杆线、水面线）必须贯穿到边缘。
8. **禁止**：悬空屋檐、无柱棚布、断头桥、底部或角落的水印/签名/文字、前景人物。

## 四、素材统一规范（后续所有素材遵守）

### 4.1 色彩 / 画风（以 6 张全景图为基准）
- **冷蓝青雾夜**：不透明区平均色应落在 `R≈10-16`、`G≈22-29`、`B≈26-38`，亮度 `0.08-0.11`。
- **低饱和**（饱和度 ≤ 0.6）；暖色只允许用于灯笼、灯光等点缀。
- **前景剪影禁止死黑**：不透明区亮度不得低于 `0.03`，前景也要保留冷蓝倾向与明暗层次，与底图连续。
- 低曝光、深色剪影、少量暖黄灯笼、层次简洁；避免太亮、太细、偏概念插画。

### 4.2 尺寸（禁止 2-4px 无谓漂移）
| 类型 | 尺寸 |
|---|---|
| 场景背景横向图 | `1672×941` |
| 桥接过渡图 | `560×941`（宽 420-640 可接受） |
| 环境单体资产 | 统一 `418×471`（现状 414-418×469-471 的漂移应归零） |

### 4.3 命名与目录
- 场景背景 → `night-city/`
- 环境单体 → `approved-runtime/environment/`
- UI / HUD → `approved-ui/`（或 `approved-runtime/hub/`）
- 命名：`<用途>-<对象>-v<序号>.png`；同一对象的多张变体用 v1/v2 区分。
- 桥接图命名：`bridge-<family>-v<N>.png`（family 见第二节，N 取 1、2），放入 `src/assets/night-city/bridge/`。

### 4.4 透明通道（重要，别搞反）
- **全景底图**：`RGB` 不透明。
- **桥接过渡图 = 整条不透明场景条**（内容全不透明，可存 `RGB` 或 `RGBA`，但不是「透明背景上的镂空物件」）。它是覆盖在接缝上的一段完整场景（天空+建筑剪影+水面倒影），左右边缘的内容必须与相邻全景图**连续**，接缝靠这种内容连续消除，不靠透明。渲染时以 `alpha=1` 整条盖在接缝区。
- **前景屋檐层 = `RGBA` 透明镂空**：屋檐/檐角剪影不透明、其余透明，让身后的天空与建筑透出（这是真正的透明背景）。
- 环境单体 / UI：`RGBA` 透明，alpha 边缘干净无锯齿残留。
