你是一名 2D 游戏场景概念/原画师。请为手游《夜市飞侠：护印突围》的「横向无限滚动地图」生成一批背景过渡图。下面是完整、自包含的规格，请严格照做。

## 一、游戏与背景
这是一款中国风「水乡夜市」横版动作游戏。地图由多张 1672×941 的横向全景图首尾相接、循环滚动构成。相邻两张全景图风格不同（闹市 / 屋脊 / 水市三套），硬拼时中间会露出竖直切线、且建筑结构对不上。
你的任务：生成一批「桥接过渡图」，盖在两张全景图的接缝正上方，让地平线、屋檐线、灯笼光向、水面倒影在接缝处连续穿过，看不出拼接。

核心原则（务必牢记）：不要糊缝，要去造桥。不要用雾、半透明遮罩、渐变、羽化来掩盖接缝——要让过渡图本身就是一段结构完整、能站得住的建筑场景。

## 二、统一画风（所有图必须遵守）
- 中国水乡夜市，低饱和**冷蓝青雾夜**：夜空与建筑以靛蓝/青灰为主，雾气弥漫。
- 低曝光、深色剪影建筑，层次简洁；避免太亮、太细、偏二次元或偏插画的概念图风格。
- 暖色（暖黄/琥珀）只用于灯笼、灯串、水面灯影等点缀，少而克制。
- 不要人物、不要文字、不要水印/签名/logo。

色彩基准（以现有 6 张全景图为锚，你的图要和它们同调）：
- 冷蓝夜不透明区平均色约 R≈10–16 / G≈22–29 / B≈26–38
- 亮度约 0.08–0.11，饱和度 ≤0.6

## 四、建筑构图规范（8 条，桥接图与前景屋檐都必须遵守）
1. 承重规则（最重要）：任何屋檐/屋顶必须能看到支撑（檐柱、墙体、或明确搭接在另一栋更高建筑的檐口上），禁止悬空屋檐。棚架/雨棚要有立柱+横梁+斜撑且立柱落地。桥要有桥墩或桥拱立于水中/岸上、桥面有栏杆、两端有引桥/台阶接岸。牌坊要有立柱+夹杆石、横枋上以斗拱托屋顶。灯笼只能挂在有锚点的结构上。
2. 统一基准线：全画面共用一条地平线/河岸线，高度与相邻全景图一致；所有建筑从这条线「生长」出来；水面线一致，倒影从水面线开始。
3. 统一透视：与相邻全景图同一视平线；柱子垂直、消失点一致；近大远小比例与两侧衔接。
4. 承接关系：左侧图 A 的最后一个结构延伸进入桥接图，被桥接图中更近/更高的结构合理承接或遮挡；右侧同理向图 B 交棒；过渡结构的屋顶要压住两侧屋檐线的交接处。
5. 光源统一：灯笼高度节奏、光向、水面倒影与两侧一致；暖灯少而克制。
6. 遮挡与纵深：前景柱/檐遮挡中景，中景遮挡远景；被遮挡处的结构仍要合理。
7. 边缘咬合（替代羽化）：左右边缘不做任何透明渐变；左缘场景与图 A 右缘的屋檐线高度、柱距节奏、地平线直接连续，右缘同理对接图 B 左缘；檐口线/栏杆线/水面线必须贯穿到边缘。
8. 禁止：悬空屋檐、无柱棚布、断头桥、水印/签名/文字、前景人物。

## 五、统一素材规范（交付前自查）
- 桥接图尺寸：560×941（宽度 420–640 可接受，高度固定 941，与全景图同高）。
- 前景屋檐 v2：建议与现有 v1 同高（约 941 高），保持可叠加。
- 色彩：冷蓝夜基准（见第二节数据），前景剪影禁止死黑（亮度 ≥0.03）。
- 透明通道（务必区分，别搞反）：
  · **桥接图 = 整条不透明场景条**（内容全不透明，可存 RGB 或 RGBA；不是透明背景上的镂空物件）。接缝靠左右边缘与相邻全景图的内容连续来消除，不靠透明；不要整张带半透明雾感。
  · **前景屋檐 v2 = RGBA 透明镂空**（屋檐剪影不透明、其余透明，让身后天空透出）。这一种才是真正的透明背景。
- 文件名必须完全按第三节的命名，不要改后缀或加空格。

## 六、验收标准（交付前请逐张自检）
- [ ] 13 张全部生成，文件名与第三节一一对应。
- [ ] 每张桥接图的屋檐/桥/棚架都有可见支撑，无悬空结构。
- [ ] 左右边缘的建筑线（檐口/栏杆/水面）与「假设的两侧全景图」连续，无透明渐变。
- [ ] 整体冷蓝夜色调，无死黑剪影，暖灯克制。
- [ ] 无水印、无文字、无人物。
- [ ] 尺寸符合第五节。

请交付时一并提供：13 张 PNG 文件（按命名），以及一句说明你如何保证每条规范的落实。
