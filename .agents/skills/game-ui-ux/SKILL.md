# Game UI UX

## Scope

Make action-critical rules visible through layout, hierarchy, affordances, icons, progress, alert state, animation, color, and responsive safe areas.

## Procedure

Keep the current action, next action, pressure, outcome, and recovery affordance readable at target mobile sizes and orientations. Use helper text only as reinforcement. Check focus and touch targets, first-viewport comprehension, disabled states, and terminal-to-replay return without changing the locked mechanic.

## Acceptance

Return a bounded UI artifact or implementation evidence tied to the frozen contract and its viewport checks.
