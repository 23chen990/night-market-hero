# Game Feel

## Scope

Add feedback that clarifies cause and consequence without changing the accepted rules or tuning contract.

## Procedure

For each core action, verify immediate visible response, readable contact or failure, stable timing across frame rates, and a short recovery path. Use small, deterministic motion, hit-stop, shake, easing, or audio layers only when they expose an existing state transition. Add a focused regression check before changing behavior.

## Acceptance

Every feedback claim names its trigger, visible signal, and evidence path. Self-checks remain separate from independent QA.
