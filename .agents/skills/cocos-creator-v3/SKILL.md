# Cocos Creator 3

## Scope

Use the repository's Cocos Creator 3.8 runtime adapter for the declared Cocos target. Do not download or discover unapproved third-party material.

## Procedure

Keep gameplay state in components and data, use engine delta time and tween APIs, preload resources before first display, and expose the declared deterministic observation API without using it as natural-player evidence. Verify touch and keyboard input, true 3D collision geometry, frame-rate stability, and isolated WeChat, Douyin, and TapTap outputs.

## Acceptance

Record the runtime entrypoint, target build command, imported asset evidence, and independent QA evidence for the exact Cocos workspace.
