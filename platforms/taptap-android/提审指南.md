# 夜市飞侠 · TapTap 资质审核提审指南

> 本工程把「夜市飞侠-护印突围」HTML5 构建装进一个 Android WebView APK，
> 用「移动游戏」形态上传 TapTap，过资质审核。游戏本体后续仍会迭代，
> 改完游戏后只要重跑 `tools/import_game.py` 再出新 APK 即可。

## 1. 怎么出 APK（两种路线）

### 路线 A：GitHub Actions 零安装（推荐）

不需要装任何 Android 工具，浏览器里点几下就有 APK。

1. 在 GitHub 新建一个仓库（例如 `night-market-hero`），把整个 `妖怪夜市/` 目录推上去。
   如果整个仓库太大，可以只推送 `runs/mobile-chart-adaptation-20260830/workspace/prototype-a/`
   一个目录作为独立仓库，再把仓库根的 `.github/workflows/build-night-market-hero-apk.yml`
   一起带过去（workflow 文件必须在仓库根的 `.github/workflows/` 下）。
2. 进仓库 → **Actions** 标签页 → 选 **"Build TapTap APK"** → **Run workflow**。
3. 等待约 3~5 分钟（首次会下载 Gradle 8.2 和 Android SDK 组件，约 250MB）。
4. 完成后在该次运行页面底部下载 **night-market-hero-debug-apk** 工件。
   解压得到 `app-debug.apk`，就是能上交的 APK。

> 注意：debug 签名足够过资质审核。如果未来要正式上线，
> 建议改用 release 签名（`assembleRelease` + 自己的 keystore）。

### 路线 B：本地构建（已装 Android Studio 时）

1. 安装 [Android Studio](https://developer.android.com/studio)（一次性，约 1.5~3GB，一路下一步）。
2. 双击工程根目录的 **`构建APK.command`**。首次会下载 Gradle 与 SDK 组件（约 250MB）。
3. 完成后：
   - APK 路径：`app/build/outputs/apk/debug/app-debug.apk`
   - 想直接装到连着 USB 的手机：`adb install -r app/build/outputs/apk/debug/app-debug.apk`

## 2. 游戏更新后重新打包装入

游戏改完（无论是改玩法、换美术、调难度），只要做两件事：

```bash
cd runs/mobile-chart-adaptation-20260830/workspace/prototype-a/platforms/taptap-android

# 1) 把最新的「夜市飞侠-护印突围-试玩版.html」重新装入 assets/
python3 tools/import_game.py

# 2)（可选）如果换了一批美术，重新出图标
python3 tools/make_icon.py

# 3)（可选）刷新提审截图
node tools/make_screenshots.cjs

# 4) 重新出 APK
双击 构建APK.command  或  push 到 GitHub 触发 Actions
```

## 3. TapTap 开发者中心提审操作步骤

打开 https://developer.taptap.cn/ ，登录你已有的开发者账号。

1. **创建游戏**
   - 顶部「我的游戏」→ **创建游戏**
   - 平台选 **Android（移动游戏）** ← 重要，不要选小游戏（这个工程是 APK，不是小游戏包）
   - 名称：`夜市飞侠`
   - 类目：建议选 **休闲 / 动作**
   - 语言：**简体中文**
   - 简介（见下方 §4）

2. **上传安装包**
   - 进入游戏详情 → **包管理** → **上传新包**
   - 选 `app-debug.apk`
   - 等 TapTap 自动签名加固后，会生成最终可分发的 APK

3. **上传游戏资料**
   - **图标**：用 `store/icon_512.png`（512×512）
   - **截图**：`store/screenshots/01.png` ~ `04.png` 里挑 3~5 张
   - **视频**（可选）：可不填

4. **资质材料**
   - **游戏适龄提示**：建议选 **8+**（轻度动作，无血腥裸露）
   - **隐私政策**（见下方 §5）
   - **版号**：资质审核阶段可先选「暂无版号 / 申请中」，拿到版号再补
   - **著作权 / 软著**：可选填，没有就先空

5. **提交审核**
   - 检查所有必填项 → 点 **提交审核**
   - 资质审核一般 1~3 个工作日。审核结果会通知你。

## 4. 游戏简介（粘贴到 TapTap）

```
【夜市飞侠：护印突围】

夜市内市，游侠受托护送一枚原创盟契铜符，要在坊门关闭前穿越整条夜市，
赶到渡口交给接应人。身后，宵禁官兵执灯火追来；身前，檐角、坊门、摊棚
之间藏着可以借力的挂点。

按住飞索挂上檐角或坊门，借力荡过夜市；松手保留动量，穿过狭窄的门洞、
绕过支起来的摊棚。一路收集金币，赶在内市牌楼落闸前突围。

— 风格：横向卷轴，简约扁平夜景，灯笼暖光
— 节奏：单局 60~120 秒，可随时复活
— 玩法：单指按住 / 松手，掌握动量即可上手
```

## 7. 已知边界 & 后续改进方向

- 当前 APK 是 **debug 签名版**，仅适合资质审核与内测。
  正式上线前请换 release 签名（生成自己的 keystore，用
  `assembleRelease` + 签名配置）。
- 图标是临时用主角美术 + 暖光晕合成的占位图，正式发行前请
  找设计师重做 1024×1024 商店图标。
- 游戏内广告按钮（"看完广告"）目前调用的是浏览器默认行为，
  上线前需要接 TapTap 广告 SDK（可参考 TapTap 官方广告文档）。
- 这版外壳是 **Android WebView**，对应的是 TapTap **移动游戏**。
  如果你后续真的要做 **TapTap 小游戏**（无 DOM 的 JS 运行时），
  那条路线需要把 DOM 版 HUD 全部重写到 Phaser canvas，工作量较大，
  不在本指南范围内。
