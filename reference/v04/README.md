# 夜市飞侠：护印突围 · v04 梁上借力

**主交付：`index.html`。这是可操作的 HTML，不是生成的整张效果图。**

这版在 v03 的真实“组件图片＋Canvas 代码组景＋环境动画”上加入两个可交互挂点、一个验证用代码角色和三处带支撑的落脚木台。地图仍是 3344×941 的有限闹市场景，不包装成完整无限地图，也不修改既有 Phaser 工程。

## 运行与操作

保存完整 `index.html`，用浏览器打开；10 张小组件图片及全部脚本均已内嵌，不请求 CDN，也不需要启动服务。聊天内的附件预览不一定执行脚本，此时请使用浏览器打开保存的 HTML。

默认停在灯绳挂点附近。点击「看一次受力」可先观察一次受力、松手和余振；点击「横梁挂点」后再次观看，可比较固定挂点。演示只重置一次初始状态，此后调用同一个物理解算器，在 1.25 秒时执行松手输入，不逐帧写入人物位置。演示结束不会把地图自动跳回链头。

| 操作 | 键盘 | 触控／鼠标 |
| --- | --- | --- |
| 移动／助摆 | A/D 或 ←/→ | 左下方向按钮 |
| 跳跃 | W 或 ↑ | 跳跃按钮 |
| 发钩并挂住 | 按住空格 | 按住金色挂点或「挂住」按钮 |
| 脱钩 | 松开空格 | 松开手指／鼠标；也可点「立即松手」 |
| 收短／放长钩锁 | Q / E | 这版仅提供键盘收放绳，触控可挂住、跳跃和助摆 |
| 重新就位 | R | 重新就位 |
| 暂停 | P | 画面右上角暂停 |
| 浏览场景 | 参数面板镜头滑杆 | 拖动非挂点位置 |

站在木台时发钩会先触发一次起跳，0.22 秒后连接。超出最大射程或挂点不在上方会拒绝连接。失足仅安全复位，不扣生命、不涉及奖励或广告。页面失去可见性时暂停，回来后需要点「继续」，不补算离开期间的运动。

## 这次真实实现的东西

### 挂点与受力

- 建筑挂点登记在 `paifang-01` 的横梁处，由程序绘制绑结和梁环，物理坐标固定。
- 灯绳挂点登记在 `high-cable-01` 的 `t=0.48` 绑结处；钩锁不扣纸灯罩。
- 玩家是归一化质量点；灯绳绑结是另一个质量点，具有回位力、阻尼和椭圆偏移限制。主钩锁用仅受拉的距离约束，不以大幅弹簧伸长代替可控摆荡。
- 物理胸部质点与朝挂点伸出的手之间有固定 reach；钩锁可见末端、真实绑结、提示环读取同一个锚点状态。代码角色手的位置由同一公式计算。
- 挂点随拉力偏移，松手保留人物速度；灯绳依靠自身回位与阻尼衰减，不靠播放固定正弦“受力动画”。
- 街道横绳是“连续静止弧线＋受力挂点影响函数”的表现模型，不是全绳有限元／真实麻绳工程模型。两个端点保持原坐标；绑结处严格到达物理挂点。
- 三盏灯笼的吊点来自变形后的绳；角运动由吊点加速度驱动并受阻尼影响。环境风摆只在此基础上叠加很小的角度。

### 场景与缓存

沿用 v03 的建筑组件、行人动画与船只。交互灯绳从静态缓存中移除，只绘制动态版本；不存在旧绳、新绳同时叠加。其余建筑继续使用静态分组缓存。人物、船只没有新增碰撞。

为留出试荡空间，`high-cable-01` 的静止下垂量从 125 调为 75 设计像素，端点不变。中央棚布从 y=553 调低到 y=622，高度由 272 改为 203，支脚仍接地；相应的棚下灯下移。新增三处木台：起步、中间缓冲和右侧落脚，每处都画出立柱、横梁及斜撑，台面高度与碰撞高度一致。

主角是本次代码绘制的可动剪影，参考项目的深色造型和红巾；**不是已验收的正式角色动作图集**。原始主角参考图保存在 `sources/`，没有把一张站姿图片横移当成动作。大屋檐、牌坊、摊棚的美术仍待后续精修，不因这版玩法可操作就视为最终画风验收。

## 检查与边界

`qa/physics-tests.json`：Node 中执行的 10 项数值检查，包括两种演示落脚、弹性与锁定对照、松手不额外加速、回弹衰减、挂点与可见曲线重合、固定步长不同刷新输入、暂停、参数边界、三组到达右台的手动输入样本。

`qa/browser-tests.json`：Chromium 中执行的 16 项功能检查，包括真实键盘及鼠标按住／松开、画布挂点命中、参数开关、暂停、导出、静态缓存复用和 844×390 / 1180×720 / 390×844 浏览器布局。

测试容器的 `file://` 导航受管理员策略限制，所以浏览器测试使用 **同一份完整离线 HTML 的 document content**。全部外网请求被拦截，不依赖外部资源。这个测试没有验证每一种手机文件查看器是否能直接运行 HTML；浏览器视口模拟也不是手机真机测试。

这些测试只覆盖有限样片和写明的输入，不是所有玩法状态可达性的证明。未完成：正式 Phaser 参数／物理接入，三地区换区与 15 张路线，流式加载／回收，真机性能，小游戏平台适配。只配置三处木台的碰撞；其余背景不因画有结构就自动可交互。本版没有钩锁绕柱、绳索打结／自碰撞、滑动抓取点或实体船体物理。

固定步长为 1/120 秒。单个超长显示帧不补跑无限步数；丢弃的超长时间计入 `droppedSeconds`。这可能造成过载时慢下来，不能据此声称低端手机稳定帧率。角色收放绳会主动做功；数值模型为游戏手感验证，不承诺真实物理能量守恒。

这份样片不计入已验收的 15 张背景素材。导出的含人物、挂点 PNG 是程序帧截图，不是无人无 UI 的正式底图。

## 源码结构

- `scene.json`：v03 延续后的静态组景和灯绳位置。
- `configs/grapple.json`：挂点、木台、试荡状态、受力参数和范围。
- `configs/ambient.json`：行人、船及环境配置。
- `assets/`：10 张独立小组件，均来自 v03；没有整张背景输入。
- `src/base-renderer-v02.js`、`ambient.js`、`renderer-v03.js`：保留原组景与活景实现。
- `src/grapple-physics.js`：与 DOM 分离的验证用解算器，可在 Node 测试。
- `src/renderer-v04.js`：动态灯绳／灯笼、挂点、木台、角色与调试绘制。
- `src/ui-v04.js`：键鼠、触控指针、视口、参数、暂停和导出。
- `template.html`：页面样式与布局。
- `build.py`：把配置、代码、组件内嵌为单文件 HTML。
- `tools/`：数值检查、浏览器检查、视频导出。
- `exports/`：实际渲染器截图及 14 秒示范视频。

## 重建与复查

只重建 HTML：`python build.py`（Python 标准库，无需 pip）。

数值检查：`node tools/test_physics.js`。

浏览器检查：先安装 `playwright` 和 `Pillow`，准备 Chromium，然后 `python tools/test_browser.py`。视频还需要系统 `ffmpeg`：`python tools/export_video.py`。脚本默认 Chromium 为 `/usr/bin/chromium`；视频导出可用 `CHROMIUM_PATH` 指定路径。

视频以 24 fps 取样，每帧推进 5 个 1/120 秒物理步。前 7 秒灯绳，后 7 秒横梁；切换时明确重新布置试荡初始状态，不代表沿地图自然通关。它是渲染结果展示，**不是实时真机性能录像**。具体方法见 `exports/video-method.json`。

## 后续工程对接点

既有 Phaser/物理工程未提供，本样片不强制选择新物理库。可提取的是挂点数据契约、动态吊点／灯笼渲染和受力表现参数；接回工程时仍要读取原来的重力、绳长、碰撞、镜头与输入条件，再用该系统重新测试可达性。正式流式地图里，正在连接的挂点必须被保护，直到脱钩后才允许回收。
