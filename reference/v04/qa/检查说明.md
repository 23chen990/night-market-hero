# v04 检查范围

Node 数值检查 10 项通过；Chromium 功能检查 16 项通过。

代码与实际执行结果分别保存在 tools/ 与 qa/*.json。测试对象是 v04 有限交互样片。

浏览器检查含挂住/松开、画布挂点命中、参数开关、PNG 和状态导出、暂停处理及 844×390/1180×720/390×844 布局。移动视口截图不是手机真机性能结果。

数值检查含固定锚点、弹性下沉和回弹、挂点/绳曲线重合、30/60/144 Hz 显示时间输入、参数极值、三个落脚输入样本；不构成对全部可能输入的可达性证明。

容器的 file:// 导航被管理策略阻止；用同一 HTML 内容装入 Chromium 测试，并拦截全部外网请求。没有验证所有手机文件查看器。

视频逐帧推进实际代码，不是实时性能录像。未做正式 Phaser 接入、无限路线、流式加载/回收和小游戏平台测试。
